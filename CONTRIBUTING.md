# Contributing

Thank you for helping. This package is a copy: it lives in Videxo's own source, next to the API it
calls, and every update replaces the files here. So every fix is made there, and pull requests here
are closed with thanks.

- **A problem with the package**: open an issue. Say what you ran and what happened, with the
  error's `code`, `detail` and `requestId` when the API answered one. We fix it at the source and
  it arrives here with the next update.
- **A question about the API or your account**: see [Get help](https://videxo.io/docs/support).
- **A security problem**: do not open an issue; email [hello@videxo.io](mailto:hello@videxo.io).

Never post an API key or a client token, in an issue or anywhere else. If a key was exposed, revoke
it in the dashboard under **API keys**.
